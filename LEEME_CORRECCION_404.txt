HUELLITAS - CORRECCIÓN ERROR HTTP 404 EN ADMIN > TIENDA
=======================================================
El panel nuevo carga dos rutas de Flask: /obtener_productos y /api/tienda/pedidos.
Un 404 indica que el servidor Python activo no tiene al menos una ruta.

INSTALACIÓN (sin borrar tu información)
1. Detén el servidor Flask abierto: vuelve a la terminal y presiona Ctrl+C.
   Si hay más servidores ejecutándose en el puerto 5000, detén también esos procesos.
2. Copia todo el CONTENIDO de este ZIP sobre la CARPETA PRINCIPAL de tu proyecto,
   es decir, la misma carpeta que contiene el archivo app.py que ejecutas.
   Acepta reemplazar los archivos del código. Respeta las subcarpetas modulos/, static/ y templates/.
3. NO REEMPLACES NI BORRES instance/huellitas.db ni instance/.clave_sesion.
   Haz copia de seguridad de la carpeta instance/ antes de comenzar.
4. En la misma carpeta que app.py ejecuta:
   python -m pip install -r requirements.txt
   python verificar_tienda.py
5. Si muestra OK en todas las rutas, ejecuta:
   python app.py
6. Visita http://127.0.0.1:5000/admin#shop (inicia sesión como administrador).
   Fuerza la actualización de navegador con Ctrl+F5.

SI PERSISTE EL ERROR
Abre /api/tienda/pedidos en tu navegador estando en la sesión de administrador.
Una respuesta JSON con status=ok significa que la API se registró correctamente.
404 significa que otra aplicación o una versión vieja de app.py está activa.
403 significa que no tienes sesión de administrador autorizada.
Si el verificador dice OK pero el navegador 404, revisa si hay dos procesos Python
sirviendo en puertos distintos, o si abriste el sitio desde otro equipo/servidor.

Este ZIP no incluye una base de datos, para preservar tus registros.
La interfaz corregida ahora identifica la ruta que falla y muestra el inventario
incluso si temporalmente no logra cargar pedidos.
